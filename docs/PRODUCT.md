# 마음모아 기획 결정 사항

## 서비스

- 이름: **마음모아**
- 한 줄 설명: 한 사람을 위한 응원 메시지를 모아 선물하는 보드
- 대상: 개인 간 선물 (단체·기업은 이후 확장. `boards.owner_id`를 개인/조직으로 넓히는 방식)

## 사용자

| 역할 | 설명 | 로그인 |
|---|---|---|
| 개설자 | 보드를 만들고 링크를 공유하고 관리·전달 | 필요 (보드 만들기 시작 단계) |
| 참여자 | 참여 링크로 들어와 메시지 작성 | 불필요 (닉네임 + 비밀번호 4자리) |
| 주인공 | 선물 링크로 결과를 감상 | 불필요 (보관하려면 로그인) |

## 테마

보드를 만들 때 선택. 메시지 데이터는 같고 모습과 문구만 바뀐다.

| 테마 | 메시지 단위 | 작성 버튼 | 결과 화면 | 출시 |
|---|---|---|---|---|
| 꽃다발 | 꽃 한 송이 | 꽃 한 송이 꽂기 | ○○의 꽃다발 | MVP |
| 밤하늘 | 별 하나 | 별 띄우기 | ○○의 밤하늘 | MVP |
| 쪽지 벽 | 쪽지 한 장 | 쪽지 붙이기 | ○○의 메모 벽 | MVP |
| 응원봉 | 응원봉 하나 | 불 밝히기 | ○○을 위한 객석 | 이후 |
| 편지함 | 편지 한 통 | 편지 넣기 | ○○의 우체통 | 이후 |

상황을 고르면 테마를 추천한다: 생일·합격 → 꽃다발, 퇴사·위로 → 밤하늘, 동료·기타 → 쪽지 벽.

## 운영 정책

| 항목 | 결정 |
|---|---|
| 참여자 수정·삭제 | 작성 시 정한 비밀번호 4자리로. 5회 틀리면 10분 잠금 |
| 개설자 권한 | 모든 메시지 수정·삭제·숨김. 수정한 메시지에는 "개설자가 수정함" 표시 |
| 다른 사람 메시지 미리 보기 | 개설자 선택, 기본 **공개** |
| 승인 후 게시 | 옵션, 기본 끔 |
| 결과 페이지 공개 | 기본 **공개** (선물 링크가 있으면 누구나), 비공개 옵션 |
| 악플 방지 | 금칙어 필터, 신고, 새 메시지 알림, 같은 기기 연속 작성 제한 |

### 링크

- **참여 링크** `/w/{join_code}`: 참여자용. 카카오톡 미리보기에 보드 제목을 그대로 보여 준다.
- **선물 링크** `/g/{gift_code}`: 주인공용. 참여 링크와 분리.

### 서프라이즈 모드 = 주인공이 언제부터 볼 수 있는가

| | ON | OFF |
|---|---|---|
| 선물 링크 생성 | 전달하기를 누를 때 | 보드를 만들자마자 |
| 주인공이 보는 시점 | 마감 후 완성본을 한 번에 | 모으는 동안 실시간으로 |
| 어울리는 상황 | 생일, 합격, 퇴사 | 투병, 시험 기간 등 위로·응원 |

기본값은 상황에 따라 정한다: 위로·응원만 OFF, 나머지는 ON. 개설자가 바꿀 수 있다.

## 보드 상태

`collecting`(모으는 중) → `closed`(마감) → `delivered`(전달됨)

## 결과 페이지

- 오프닝 연출 (건너뛰기 가능) → 테마 장면이 첫 화면 → 메시지 카드 / 목록 보기(모아 보기, 한 장씩)
- 하단: 이미지 저장, 공유, 나도 마음모아 만들기
- 메시지 수에 따라 장면 확장 (적으면 크게, 50개 이상이면 은하수·꽃밭 등)
